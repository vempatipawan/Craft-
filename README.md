# Craft Coffee & Pastry — final design round

Homepage and product page, desktop and mobile. Built for the final round of the
Craft website rebuild, 7 September 2026.

**Open it:** [vempatipawan.github.io/Craft-](https://vempatipawan.github.io/Craft-/)

It is a real responsive prototype rather than flat artboards, so the fastest way
to judge the mobile work is to open that link on a phone. Tap between Pickup and
Delivery on the product page, change the quantity, and scroll until the buy bar
appears at the bottom.

| | |
|---|---|
| `index.html` | Cover page, and the seven places the supplied direction was taken further |
| `home.html` | Homepage |
| `product.html` | Product page |
| `craft.css` | The entire stylesheet. One file |

## Built from the supplied direction

Playfair Display and Inter. The five Craft colour tokens unchanged:
`#1B120E` `#DCCBA8` `#F6F3EF` `#6B4F3A` `#2E5D3A`.

Every product name, price, description and photograph comes from
craft-amsterdam.nl. No placeholder text, no stock imagery.

## What it is made of

Plain HTML and CSS. No page builder, no framework, no build step, no jQuery,
no dependencies. Markup and styles together are 47 KB.

| | This prototype | craft-amsterdam.nl today |
|---|---|---|
| Homepage on mobile | 357 KB | 2,480 KB |
| Product page | 387 KB | 617 KB |

Measured on the same method used for the site audit: a mid-range phone profile,
four times processor slowdown, roughly 1.6 Mbps.

## A note on the photography

The croissants and pastries are Craft's own 2026 product shots. The bakery and
story images are from 2020, because those are what exist today. Every layout is
built so new photography drops in without a redesign.
